# Smooth Glass Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Real, smooth glass everywhere in Bearoom — including over the playing video — by replacing the window-capturing Android blur with a per-surface engine and adding iOS Liquid Glass.

**Architecture:** One `Glass` component picks an engine per surface with a pure function (`selectGlassEngine`). Android 12+ blurs an explicit `GlassBackdrop` through our own local Expo module (`modules/bearoom-glass`) that renders a glass-sized `RenderNode` with `RenderEffect` blur; iOS uses `expo-glass-effect` (Liquid Glass) and `expo-blur` (system blur); everything else gets crafted glass (tint + lift + highlight). Backdrops are registered per focused screen or per local `GlassLayer` (the player), and a glass never blurs a backdrop it sits inside.

**Tech Stack:** Expo SDK 57, RN 0.86 (Fabric), TypeScript, Jest (jest-expo, react-test-renderer), Kotlin (Expo Modules API, `RenderNode`/`RenderEffect` API 31), `expo-blur` 57.0.3, `expo-glass-effect` 57.0.4, `expo-linear-gradient`.

**Spec:** `docs/superpowers/specs/2026-10-11-glass-design.md`

## Global Constraints

- Android real blur only through `modules/bearoom-glass` on API 31+; **never** a window-wide capture, software rasterising, or timers (spec D3, D7).
- iOS: Liquid Glass (`expo-glass-effect`) for `control`/`bar` on iOS 26+; system blur (`expo-blur`) for `chrome`/`sheet` and on iOS < 26 (spec D2).
- `crafted` whenever Reduce Transparency is on, Android < 12, the caller passes `backdrop="none"` (inside a `Modal`), or the only backdrop is one the glass sits inside (spec D2, D4).
- Never edit `src/ui/BearAlert.tsx`; `Frost` stays as `Glass material="sheet" backdrop="none"` (spec D7).
- No Reanimated `entering`/`exiting`/`layout` props.
- Colors live in `theme/` only (new rgba values go in `theme/bearoom.ts`).
- Performance is measured on the **release** build on the Nothing Phone 1 (`P2228K000422`), never a dev build.
- Every commit ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. A glass whose backdrop unmounts while the glass stays (details screen popped, player source switched remounts the video) → it must fall back to crafted, never draw a detached node or crash. Pinned in Task 3 ("falls back to crafted when its backdrop unmounts") + native `isAttachedToWindow` check in Task 2.
2. Fast tab switches → the tab bar must blur the focused tab, never a stale one. Pinned in Task 1 ("tab switches").
3. Player controls fading → Liquid Glass must switch to `none` when hidden and back on show. Pinned in Task 3 (liquid fade) and Task 6 (controls pass `visible`).
4. Glass inside the player layer must never blur the whole screen, even before the video backdrop mounts. Pinned in Task 3 ("inside a GlassLayer…").
5. Rotation / fullscreen resizes the player → the Android blur must follow its new offset and size. Native pre-draw offset check in Task 2; device check in Task 8 step 6.

```ts
/**
 * Which glass engine draws a surface — one pure decision, so every platform rule lives in one place.
 * Spec: docs/superpowers/specs/2026-10-11-glass-design.md §3 D2.
 */
export type GlassMaterial = "control" | "bar" | "chrome" | "sheet";
export type GlassEngine = "liquid" | "material" | "backdrop" | "crafted";
/** available = a backdrop this glass may blur; none = nothing to blur; inside = the only backdrop is one it sits inside. */
export type BackdropState = "available" | "none" | "inside";

export interface EngineInput {
  os: string;
  /** Android API level (Platform.Version); ignored elsewhere. */
  androidApi: number;
  /** iOS 26+ Liquid Glass API present. */
  liquidAvailable: boolean;
  reduceTransparency: boolean;
  material: GlassMaterial;
  backdrop: BackdropState;
}

/** RenderNode + RenderEffect both exist from Android 12 (API 31). */
export const ANDROID_BLUR_MIN_API = 31;

export function selectGlassEngine(i: EngineInput): GlassEngine {
  if (i.reduceTransparency) return "crafted";
  if (i.os === "ios") {
    const floating = i.material === "control" || i.material === "bar";
    return floating && i.liquidAvailable ? "liquid" : "material";
  }
  if (i.os === "android" && i.androidApi >= ANDROID_BLUR_MIN_API && i.backdrop === "available") return "backdrop";
  return "crafted";
}
```

`src/ui/glass/registry.ts`:
```ts
import type { RefObject } from "react";
import type { View } from "react-native";
import type { BackdropState } from "./engine";

export interface BackdropEntry {
  id: number;
  ref: RefObject<View | null>;
}

/** An ordered set of backdrops; the most recently added one is current. */
export interface BackdropRegistry {
  add(entry: BackdropEntry): void;
  remove(id: number): void;
  current(): BackdropEntry | null;
  subscribe(listener: () => void): () => void;
}

export function createBackdropRegistry(): BackdropRegistry {
  let entries: BackdropEntry[] = [];
  const listeners = new Set<() => void>();
  const emit = () => listeners.forEach((l) => l());
  return {
    add(entry) {
      entries = [...entries.filter((e) => e.id !== entry.id), entry];
      emit();
    },
    remove(id) {
      const next = entries.filter((e) => e.id !== id);
      if (next.length === entries.length) return;
      entries = next;
      emit();
    },
    current: () => entries[entries.length - 1] ?? null,
    subscribe(listener) {
      listeners.add(listener);
      return () => {
        listeners.delete(listener);
      };
    },
  };
}

/** Backdrops of focused screens: floating chrome (tab bar, peek bar, headers) blurs the current one. */
export const screenBackdrops = createBackdropRegistry();

let lastId = 0;
export const nextBackdropId = (): number => ++lastId;

/** What a glass may blur: its backdrop, unless it opted out or sits inside it. */
export function resolveBackdrop(
  mode: "auto" | "none",
  entry: BackdropEntry | null,
  insideIds: readonly number[],
): { entry: BackdropEntry | null; state: BackdropState } {
  if (mode === "none" || !entry) return { entry: null, state: "none" };
  if (insideIds.includes(entry.id)) return { entry: null, state: "inside" };
  return { entry, state: "available" };
}
```

```kotlin
package expo.modules.bearoomglass

import android.content.Context
import android.graphics.Canvas
import android.graphics.RenderNode
import android.os.Build
import androidx.annotation.RequiresApi
import expo.modules.kotlin.AppContext
import expo.modules.kotlin.views.ExpoView

/**
 * What glass may blur. Records its children into a RenderNode during its normal draw (no extra work — it is
 * the draw that happens anyway) and draws that node; BearoomGlassView draws the same node, blurred.
 */
class BearoomGlassBackdropView(context: Context, appContext: AppContext) : ExpoView(context, appContext) {
  private val recorder: Recorder? =
    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.S) Recorder() else null

  /** The recorded children, or null below Android 12. */
  val renderNode: RenderNode?
    get() = if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.S) recorder?.node else null

  // React Native positions the children; LinearLayout (ExpoView's base) must not re-arrange them.
  override fun onLayout(changed: Boolean, l: Int, t: Int, r: Int, b: Int) {}

  override fun dispatchDraw(canvas: Canvas) {
    val rec = recorder
    if (rec == null || Build.VERSION.SDK_INT < Build.VERSION_CODES.S || !canvas.isHardwareAccelerated) {
      super.dispatchDraw(canvas)
      return
    }
    rec.draw(canvas, width, height) { super.dispatchDraw(it) }
  }

  @RequiresApi(Build.VERSION_CODES.S)
  private class Recorder {
    val node = RenderNode("BearoomGlassBackdrop")

    fun draw(canvas: Canvas, width: Int, height: Int, drawChildren: (Canvas) -> Unit) {
      node.setPosition(0, 0, width, height)
      val recording = node.beginRecording()
      try {
        drawChildren(recording)
      } finally {
        node.endRecording()
      }
      canvas.drawRenderNode(node)
    }
  }
}
```

`BearoomGlassView.kt`:
```kotlin
package expo.modules.bearoomglass

import android.content.Context
import android.graphics.Canvas
import android.graphics.Color
import android.graphics.ColorMatrix
import android.graphics.ColorMatrixColorFilter
import android.graphics.RenderEffect
import android.graphics.RenderNode
import android.graphics.Shader
import android.os.Build
import android.view.View
import android.view.ViewTreeObserver
import androidx.annotation.RequiresApi
import expo.modules.kotlin.AppContext
import expo.modules.kotlin.views.ExpoView
import kotlin.math.ceil

/**
 * Real glass on Android 12+. Draws its backdrop's RenderNode — clipped to this view plus a blur margin — into a
 * small RenderNode carrying a RenderEffect blur, then an overlay tint. The offscreen layer is this view's size,
 * not the backdrop's, so a tab bar costs a tab bar's worth of GPU. No window capture, no software drawing, no
 * timers: content changes flow through because the small node references the backdrop's node.
 */
class BearoomGlassView(context: Context, appContext: AppContext) : ExpoView(context, appContext) {
  private val blur: Blur? = if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.S) Blur() else null
  private var backdrop: BearoomGlassBackdropView? = null
  private var blurRadiusDp = 20f
  private var saturation = 1f
  private var overlayColor = Color.TRANSPARENT
  private val own = IntArray(2)
  private val theirs = IntArray(2)
  private var drawnDx = Int.MIN_VALUE
  private var drawnDy = Int.MIN_VALUE

  // Scrolling and transitions move this view (or the backdrop) without redrawing it: re-check the offset each
  // frame — two getLocationInWindow calls — and redraw only when it changed.
  private val offsetWatcher = ViewTreeObserver.OnPreDrawListener {
    val b = backdrop
    if (blur != null && b != null && b.isAttachedToWindow) {
      measureOffset(b)
      if (own[0] != drawnDx || own[1] != drawnDy) invalidate()
    }
    true
  }

  init {
    setWillNotDraw(false)
  }

  fun setBackdropTag(tag: Int?) {
    backdrop = tag?.let { appContext.findView<BearoomGlassBackdropView>(it) }
    drawnDx = Int.MIN_VALUE
    invalidate()
  }

  fun setBlurRadiusDp(dp: Float) {
    if (dp == blurRadiusDp) return
    blurRadiusDp = dp
    blur?.markDirty()
    invalidate()
  }

  fun setSaturation(value: Float) {
    if (value == saturation) return
    saturation = value
    blur?.markDirty()
    invalidate()
  }

  fun setOverlayColor(color: Int) {
    if (color == overlayColor) return
    overlayColor = color
    invalidate()
  }

  override fun onAttachedToWindow() {
    super.onAttachedToWindow()
    viewTreeObserver.addOnPreDrawListener(offsetWatcher)
  }

  override fun onDetachedFromWindow() {
    viewTreeObserver.removeOnPreDrawListener(offsetWatcher)
    super.onDetachedFromWindow()
  }

  override fun onLayout(changed: Boolean, l: Int, t: Int, r: Int, b: Int) {}

  override fun onDraw(canvas: Canvas) {
    super.onDraw(canvas)
    val b = backdrop
    val source = b?.renderNode
    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.S && blur != null && b != null && source != null &&
      canvas.isHardwareAccelerated && b.isAttachedToWindow && width > 0 && height > 0 && !isInside(b)
    ) {
      measureOffset(b)
      drawnDx = own[0]
      drawnDy = own[1]
      val radiusPx = blurRadiusDp * resources.displayMetrics.density
      blur.draw(canvas, source, width, height, drawnDx, drawnDy, radiusPx, saturation)
    }
    if (overlayColor != Color.TRANSPARENT) canvas.drawColor(overlayColor)
  }

  /** Leaves this view's offset from the backdrop in own[0], own[1]. */
  private fun measureOffset(b: View) {
    getLocationInWindow(own)
    b.getLocationInWindow(theirs)
    own[0] -= theirs[0]
    own[1] -= theirs[1]
  }

  /** Drawing a backdrop we sit inside would make the render tree contain itself (libhwui recursion crash). */
  private fun isInside(b: View): Boolean {
    var p = parent
    while (p != null) {
      if (p === b) return true
      p = p.parent
    }
    return false
  }

  @RequiresApi(Build.VERSION_CODES.S)
  private class Blur {
    private val node = RenderNode("BearoomGlass")
    private var effectDirty = true

    fun markDirty() {
      effectDirty = true
    }

    fun draw(canvas: Canvas, source: RenderNode, width: Int, height: Int, dx: Int, dy: Int, radiusPx: Float, saturation: Float) {
      val margin = ceil(radiusPx).toInt()
      node.setPosition(0, 0, width + 2 * margin, height + 2 * margin)
      val recording = node.beginRecording()
      try {
        recording.translate((margin - dx).toFloat(), (margin - dy).toFloat())
        recording.drawRenderNode(source)
      } finally {
        node.endRecording()
      }
      if (effectDirty) {
        node.setRenderEffect(effect(radiusPx, saturation))
        effectDirty = false
      }
      canvas.save()
      canvas.clipRect(0, 0, width, height)
      canvas.translate(-margin.toFloat(), -margin.toFloat())
      canvas.drawRenderNode(node)
      canvas.restore()
    }

    private fun effect(radiusPx: Float, saturation: Float): RenderEffect {
      val r = radiusPx.coerceAtLeast(1f)
      val blur = RenderEffect.createBlurEffect(r, r, Shader.TileMode.CLAMP)
      if (saturation == 1f) return blur
      val lift = ColorMatrix().apply { setSaturation(saturation) }
      return RenderEffect.createChainEffect(RenderEffect.createColorFilterEffect(ColorMatrixColorFilter(lift)), blur)
    }
  }
}
```

```ts
import { useSyncExternalStore } from "react";
import { AccessibilityInfo, Platform } from "react-native";

let reduce = false;
let started = false;
const listeners = new Set<() => void>();
const set = (v: boolean) => {
  reduce = v;
  listeners.forEach((l) => l());
};

/** One OS subscription shared by every glass surface. */
function start() {
  if (started || Platform.OS !== "ios") return;
  started = true;
  AccessibilityInfo.isReduceTransparencyEnabled().then(set, () => {});
  AccessibilityInfo.addEventListener("reduceTransparencyChanged", set);
}

/** iOS "Reduce Transparency": glass draws its solid look while it's on. */
export function useReduceTransparency(): boolean {
  return useSyncExternalStore(
    (listener) => {
      start();
      listeners.add(listener);
      return () => {
        listeners.delete(listener);
      };
    },
    () => reduce,
  );
}
```

```tsx
import { useScreenFocused } from "@/hooks/useScreenFocused";
import { NativeGlassBackdrop } from "@/modules/bearoom-glass";
import React, { createContext, useContext, useEffect, useMemo, useRef, useState, type ReactNode } from "react";
import type { StyleProp, View, ViewStyle } from "react-native";
import { createBackdropRegistry, nextBackdropId, screenBackdrops, type BackdropRegistry } from "./registry";

/** A GlassLayer's private backdrop slot; null outside any layer. */
export const GlassLayerContext = createContext<BackdropRegistry | null>(null);
/** Ids of the backdrops this subtree sits inside. */
export const GlassInsideContext = createContext<readonly number[]>([]);

/** A private backdrop for its subtree — the player's controls blur the video box, not the screen. */
export function GlassLayer({ children }: { children: ReactNode }) {
  const slot = useMemo(() => createBackdropRegistry(), []);
  return <GlassLayerContext.Provider value={slot}>{children}</GlassLayerContext.Provider>;
}

/**
 * What glass may blur. Inside a GlassLayer it fills that layer's slot; otherwise it is its screen's backdrop
 * while the screen is focused (the tab bar, peek bar and headers blur it).
 */
export function GlassBackdrop({ style, children }: { style?: StyleProp<ViewStyle>; children?: ReactNode }) {
  const ref = useRef<View>(null);
  const [id] = useState(nextBackdropId);
  const entry = useMemo(() => ({ id, ref }), [id]);
  const layer = useContext(GlassLayerContext);
  const focused = useScreenFocused();
  const outer = useContext(GlassInsideContext);
  const inside = useMemo(() => [...outer, id], [outer, id]);

  useEffect(() => {
    const registry = layer ?? (focused ? screenBackdrops : null);
    if (!registry) return;
    registry.add(entry);
    return () => registry.remove(entry.id);
  }, [layer, focused, entry]);

  return (
    <GlassInsideContext.Provider value={inside}>
      <NativeGlassBackdrop ref={ref} style={style} collapsable={false}>
        {children}
      </NativeGlassBackdrop>
    </GlassInsideContext.Provider>
  );
}
```

```tsx
import { NativeGlassView } from "@/modules/bearoom-glass";
import { glassHighlight, glassLift, glassMaterials } from "@/theme/bearoom";
import { BlurView } from "expo-blur";
import { GlassView } from "expo-glass-effect";
import { LinearGradient } from "expo-linear-gradient";
import React, { useContext, useSyncExternalStore } from "react";
import { processColor, StyleSheet, View, type StyleProp, type ViewStyle } from "react-native";
import { selectGlassEngine, type GlassMaterial } from "./engine";
import { GlassInsideContext, GlassLayerContext } from "./GlassBackdrop";
import { glassPlatform, nativeTagOf } from "./platform";
import { resolveBackdrop, screenBackdrops } from "./registry";
import { useReduceTransparency } from "./useReduceTransparency";

export interface GlassProps {
  /** What kind of surface this is (spec D1). */
  material?: GlassMaterial;
  /** "none" = never blur what's behind — surfaces inside a Modal (a separate window on Android). */
  backdrop?: "auto" | "none";
  /** False while the surface is faded out: Liquid Glass must not sit at alpha 0 (expo #41024). */
  visible?: boolean;
  /** Corner radius of the glass shape. */
  radius?: number;
  /** Liquid Glass reacts to touches (buttons). */
  interactive?: boolean;
  /** Defaults to filling the parent. */
  style?: StyleProp<ViewStyle>;
}

/**
 * The glass layer behind a glassy surface: real blur where it is smooth and safe (Liquid Glass or the system
 * blur on iOS, a backdrop blur on Android 12+), crafted glass — tint, warm lift, top highlight — elsewhere.
 * Spec: docs/superpowers/specs/2026-10-11-glass-design.md.
 */
export function Glass({ material = "control", backdrop = "auto", visible = true, radius = 0, interactive = false, style }: GlassProps) {
  const layer = useContext(GlassLayerContext);
  const inside = useContext(GlassInsideContext);
  const registry = layer ?? screenBackdrops;
  const current = useSyncExternalStore(registry.subscribe, registry.current);
  const reduceTransparency = useReduceTransparency();
  const resolved = resolveBackdrop(backdrop, current, inside);
  const engine = selectGlassEngine({ ...glassPlatform, reduceTransparency, material, backdrop: resolved.state });
  const m = glassMaterials[material];
  const shape = [style ?? StyleSheet.absoluteFill, { borderRadius: radius, overflow: "hidden" as const }];

  if (engine === "liquid") {
    return (
      <GlassView
        pointerEvents="none"
        style={shape}
        glassEffectStyle={{ style: visible ? "regular" : "none", animate: true, animationDuration: 0.2 }}
        tintColor={m.liquidTint}
        colorScheme="dark"
        isInteractive={interactive}
      />
    );
  }

  const fill = engine === "crafted" ? m.solid : engine === "material" ? m.tint : null;
  return (
    <View pointerEvents="none" style={shape}>
      {engine === "material" ? <BlurView tint="dark" intensity={m.iosIntensity} style={StyleSheet.absoluteFill} /> : null}
      {engine === "backdrop" && NativeGlassView ? (
        <NativeGlassView
          style={StyleSheet.absoluteFill}
          backdropTag={nativeTagOf(resolved.entry?.ref.current ?? null)}
          blurRadius={m.blur}
          saturation={m.saturation}
          overlayColor={processColor(m.tint) as number}
        />
      ) : null}
      {fill ? <View style={[StyleSheet.absoluteFill, { backgroundColor: fill }]} /> : null}
      <View style={[StyleSheet.absoluteFill, { backgroundColor: glassLift }]} />
      <LinearGradient colors={[glassHighlight, "transparent"]} locations={[0, 0.55]} style={StyleSheet.absoluteFill} />
    </View>
  );
}

export default Glass;
```

```tsx
/**
 * GlassCard — a glass surface (Glass + hairline border) for bars, sheets, CTA cards and grouped rows.
 * blur={false} draws a plain warm tint instead (repeated cards inside lists).
 */
import { colors, radius } from "@/theme/bearoom";
import React from "react";
import { StyleSheet, View, type ViewProps } from "react-native";
import { Glass, type GlassMaterial } from "./glass";

interface Props extends ViewProps {
  blur?: boolean;
  /** Glass material; floating bars by default. */
  material?: GlassMaterial;
  /** False while the card is faded out (player controls). */
  visible?: boolean;
  rounded?: number;
  bordered?: boolean;
  /** Inner padding; true = 16, or a number. */
  padded?: boolean | number;
}

export function GlassCard({
  blur = true,
  material = "bar",
  visible = true,
  rounded = radius.xl,
  bordered = true,
  padded = false,
  style,
  children,
  ...rest
}: Props) {
  const pad = padded === true ? 16 : typeof padded === "number" ? padded : 0;
  return (
    <View
      style={[
        { borderRadius: rounded, overflow: "hidden", backgroundColor: blur ? "transparent" : colors.surfaceStrong },
        bordered && { borderWidth: StyleSheet.hairlineWidth, borderColor: colors.border },
        style,
      ]}
      {...rest}
    >
      {blur ? <Glass material={material} visible={visible} radius={rounded} /> : null}
      <View style={{ padding: pad }}>{children}</View>
    </View>
```
