# Expo SDK 53 → 57 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move Bearoom from Expo SDK 53 (RN 0.79.6) to Expo SDK 57.0.27 (RN 0.86.3) so the app builds and launches on
Xcode 27 / iOS 27, without changing anything the user sees except iPhone players now being able to rotate.

**Architecture:** Make `app.json` + config plugins the single source of truth for the native projects first (SDK 57's
`prebuild` cleans by default), then step 53 → 54 → 55 → 57 on branch `upgrade/expo-57`, proving each step on the
Android emulator, and iOS at 57 with `expo-build-properties` `ios.enableSceneSupport`.

**Tech Stack:** Expo SDK 54/55/57 · React Native 0.81 → 0.83 → 0.86 · Reanimated 4 + react-native-worklets ·
FlashList 2 · patch-package · jest-expo · Xcode 27 (`xcodebuild` + `xcrun simctl`, no Simulator.app on this Mac).

**Spec:** [`docs/superpowers/specs/2026-10-10-playback-languages-party-design.md`](../specs/2026-10-10-playback-languages-party-design.md)
(§3 constraints; §9 — every later phase's iOS gate depends on this). Impact evidence:
[`docs/research/sdk57-upgrade-impact-2026-10.md`](../../research/sdk57-upgrade-impact-2026-10.md) (cited below as
"impact §x").

## Global Constraints

- Work on branch `upgrade/expo-57`; `feat/improvements` stays untouched until Task 7 merges a green result.
- Target **expo 57.0.27** (must be ≥ 57.0.23 for scene support and ≥ 57.0.9 for the Hermes V1 memory fix).
- No live blur and no elevation/glow on any screen that plays video. **No Reanimated `entering`/`exiting`/`layout`.**
  Never touch `src/ui/BearAlert.tsx` except the single `absoluteFillObject` → `absoluteFill` swap (Task 3).
- No user-visible change except: iPhone players can rotate to landscape (they couldn't — Info.plist was portrait-only).
- Deploy/Cloudflare commands are not part of this plan. Commit trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Verification on this Mac: Android emulator `emulator-5554`; iOS simulator `A1518C83-9D37-419D-9865-9CDDC16F11E3`
  (iOS 27). Bearoom's JS runtime is read over Metro's CDP proxy (`scratchpad/cdp/rn-eval.mjs`), because metro-mcp
  attaches to whichever app connected first.

## Review Focus

1. **Background playback keep-alive** (Home pressed while a video plays) depends on the WebView patch, which must be
   regenerated for each webview version. → Task 4/6 step "patch applies" + Task 7 device check.
2. **False "Try another source" overlays**: webview 13.16 stops suppressing spurious Android `onReceivedError`.
   → Task 7 device check on VidFast.
3. **`expo/fetch` becomes global `fetch` (SDK 56)**: `/config`, TMDB, KLIPY, Supabase realtime must still work.
   → Task 7 smoke checks.
4. **iOS deep links after the scene delegate** (`bearoom://movie/550`). → Task 7.
5. **Orientation**: portrait everywhere, landscape allowed in Player/Party on both platforms. → Task 2 and Task 7.

- [ ] **Step 4: Implement `addPlaybackToMainApplication`** — in `withBearoomPlayback.js`, replace
  `withBearoomPlaybackMainApplication` (lines 142-169) with:

```js
// SDK 53 builds the list as `val packages = PackageList(this).packages` and adds with
// `packages.add(...)`; SDK 54+ uses `PackageList(this).packages.apply { … }` and `add(...)`.
const MODERN_PACKAGES = /PackageList\(this\)\.packages\.apply \{/;
const LEGACY_PACKAGES = /val packages = PackageList\(this\)\.packages/;
// Present in every template from SDK 53 to 57 (SDK 55 deletes ReactNativeHostWrapper).
const IMPORT_ANCHOR = /import expo\.modules\.ApplicationLifecycleDispatcher/;

function addPlaybackToMainApplication(contents, pkg) {
  if (!IMPORT_ANCHOR.test(contents)) {
    throw new Error(`${PLUGIN_NAME}: anchor not found in MainApplication (ApplicationLifecycleDispatcher import)`);
  }
  let out = mergeContents({
    tag: `${PLUGIN_NAME}-main-application-import`,
    src: contents,
    newSrc: `import ${pkg}.playback.BearoomPlaybackPackage`,
    anchor: IMPORT_ANCHOR,
    offset: 1,
    comment: "//",
  }).contents;
  const modern = MODERN_PACKAGES.test(out);
  if (!modern && !LEGACY_PACKAGES.test(out)) {
    throw new Error(`${PLUGIN_NAME}: anchor not found in MainApplication (PackageList)`);
  }
  out = mergeContents({
    tag: `${PLUGIN_NAME}-main-application-package`,
    src: out,
    newSrc: modern
      ? `              add(${pkg}.playback.BearoomPlaybackPackage())`
      : `            packages.add(${pkg}.playback.BearoomPlaybackPackage())`,
    anchor: modern ? MODERN_PACKAGES : LEGACY_PACKAGES,
    offset: 1,
    comment: "//",
  }).contents;
  return out;
}

const withBearoomPlaybackMainApplication = (config) =>
  withMainApplication(config, (cfg) => {
    cfg.modResults.contents = addPlaybackToMainApplication(cfg.modResults.contents, getAndroidPackage(cfg));
    return cfg;
  });
```

and at the bottom of the file keep the existing `module.exports = …` and add
`module.exports.addPlaybackToMainApplication = addPlaybackToMainApplication;`.

- [ ] **Step 5: Implement `addXcodeFixesToPodfile`** — in `with-fmt-xcode-fix.js`, make the floor a parameter of the
  generated Ruby and the anchor match both templates:

```js
const DEPLOYMENT_FLOOR = "15.1"; // raised to "16.4" at SDK 57 (Task 6)
const CCACHE_ANCHOR =
  /:ccache_enabled => (?:podfile_properties\['apple\.ccacheEnabled'\] == 'true'|ccache_enabled\?\(podfile_properties\)),/;

function postInstall(floor) {
  return POST_INSTALL.replace(/'15\.1'/g, `'${floor}'`);
}

function addXcodeFixesToPodfile(contents, floor = DEPLOYMENT_FLOOR) {
  if (!CCACHE_ANCHOR.test(contents)) {
    throw new Error(`${PLUGIN_NAME}: anchor not found in Podfile (react_native_post_install :ccache_enabled)`);
  }
  return mergeContents({
    tag: `${PLUGIN_NAME}-post-install`,
    src: contents,
    newSrc: postInstall(floor),
    anchor: CCACHE_ANCHOR,
    offset: 2,
    comment: "#",
  }).contents;
}

const withFmtXcodeFix = (config) =>
  withPodfile(config, (cfg) => {
    cfg.modResults.contents = addXcodeFixesToPodfile(cfg.modResults.contents);
    return cfg;
  });

module.exports = createRunOncePlugin(withFmtXcodeFix, PLUGIN_NAME);
module.exports.addXcodeFixesToPodfile = addXcodeFixesToPodfile;
module.exports.DEPLOYMENT_FLOOR = DEPLOYMENT_FLOOR;
```

(`POST_INSTALL` keeps its current Ruby, whose two `'15.1'` literals `postInstall()` rewrites.)
